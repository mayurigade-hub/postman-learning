# Day 00 — Postman Basics & Wanderlust API Practice

## Overview

This section documents my initial hands-on experience with Postman using my Wanderlust project (Express.js, Node.js and MongoDB).

## Topics Covered

### 1. Postman Basics
- Understanding API requests and responses.
- HTTP methods: GET, POST, PUT and DELETE.
- Working with request URLs.
- Understanding response status and body.

### 2. GET Requests
- Fetch all listings.
- Fetch a particular listing using its ID.
- Inspect HTML responses in Postman.

### 3. POST Request
- Creating a new listing.
- Sending data using raw JSON.
- Understanding `express.json()` middleware.
- Understanding the expected request body structure.

### 4. Authentication
- Testing user login.
- Sending credentials using `x-www-form-urlencoded`.
- Understanding session-based authentication.
- Inspecting session cookies (`connect.sid`).

### 5. PUT Request
- Updating an existing listing.
- Sending updated listing data using JSON.
- Understanding PUT requests.

### 6. DELETE Request
- Deleting an existing listing.
- Verifying deletion in MongoDB.

## Practical Project

**Project:** Wanderlust

**Base URL:** `http://localhost:8080`

**Tools:** Postman, Express.js, Node.js and MongoDB.

## Learning Outcome

Learned how to send different HTTP requests, inspect API responses, work with JSON request bodies and test session-based authentication using Postman.
