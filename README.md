# Postman Learning 🚀

A hands-on journey to learning Postman and API testing using my **Wanderlust project** (Node.js, Express.js and MongoDB).

## 🎯 Objectives

- Learn Postman fundamentals and advanced concepts.
- Understand HTTP requests, responses and status codes.
- Organize and manage API collections.
- Work with authentication, cookies, variables and environments.
- Perform automated API testing.
- Test APIs using Collection Runner.
